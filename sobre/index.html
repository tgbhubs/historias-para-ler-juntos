Sobre o projeto

Uma biblioteca de livros infantis interativos e gratuitos.

O que é isso?

Histórias para Ler Juntos é uma biblioteca digital de livros infantis interativos. As histórias foram criadas para serem lidas em voz alta por adultos e crianças — com momentos de escolha que mudam o caminho da narrativa.

Nenhum cadastro é necessário. Nenhum dado pessoal é coletado. As histórias são gratuitas.

Quem criou?

As histórias e o site foram criados por Tarcísio Guadalupe Buzelin.

Como funciona?

Cada livro tem uma série de páginas ilustradas. Em alguns momentos, a história pede que você e a criança tomem uma decisão juntos. Cada escolha leva a um caminho diferente. É possível reiniciar e explorar outros caminhos.

O progresso fica salvo no dispositivo (via localStorage), então é possível continuar de onde parou. Nenhuma informação é enviada para servidores.

Licença

Os livros são disponibilizados sob a licença Creative Commons CC BY 4.0. Você pode baixar, compartilhar, imprimir e adaptar, desde que a autoria seja atribuída corretamente.

❤️ Apoie o projeto

Todos os livros desta biblioteca são disponibilizados gratuitamente. Se alguma história proporcionou um momento especial para sua família, você pode contribuir voluntariamente para ajudar na criação de novas aventuras.
