Privacidade

Dados coletados

Este site não coleta dados pessoais. Não há cadastro, login ou formulários de dados.

localStorage

O progresso de leitura (última página lida em cada livro) é salvo localmente no seu dispositivo usando localStorage. Essas informações ficam somente no seu dispositivo e nunca são enviadas a nenhum servidor.

Para limpar esse dado, acesse o gerenciador de armazenamento do seu navegador ou use a opção "Recomeçar" disponível ao final de cada história.

GitHub Pages

Este site é hospedado pelo GitHub Pages. O GitHub pode registrar acessos de acordo com sua própria política de privacidade.

Crianças

Este site não coleta, solicita ou armazena dados de crianças. A experiência foi projetada para ser usada por adultos junto com crianças, sem qualquer interação individual da criança com sistemas de dados.

Contato

Dúvidas sobre privacidade podem ser enviadas via GitHub.
